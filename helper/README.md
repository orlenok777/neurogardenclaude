# Помощница: 3D-лицо, которое ведёт по играм (ветка-песочница, версия 3.7)

Эта папка есть только в ветке `sandbox-3d-helper`. Основная ветка `main` и опубликованный сайт её не содержат.

## Что это

Перед каждой из 27 игр показывается одно 3D-лицо и три кнопки: «Объясни правила», «Повтори», «Начать».
Во время игры остаётся маленькое лицо и кнопка «Подсказка». После раунда помощница показывает и произносит свой
комментарий. Голос — синтез речи самого браузера (`speechSynthesis`), ничего не скачивается и никуда не отправляется.
Если в настройках выключены звуки, сама она не заговаривает; кнопки «Объясни правила», «Повтори» и «Подсказка» работают.

## Что добавлено в 3.7

- **Помощница во всех играх** и её комментарий после раунда (в 3.6 она была только в играх на память).
- **Тренировка с помощницей.** Кнопка в саду: помощница ведёт по четырём упражнениям дня (память, внимание, логика,
  пространство), сама объясняет правила каждого и в конце подводит итог.
- **Совет по уровню.** Уровень, предложенный для следующего раунда, зависит от двух последних завершённых раундов
  этой игры: два результата от 85% на одном уровне поднимают его, два ниже 50% опускают, иначе остаётся прежний.
  Игрок может выбрать любой уровень сам. Раньше предлагался самый высокий пройденный уровень.
- **Игра «Двойное решение»** (внимание). На короткое время в центре показывается яблоко или груша, на краю — жук;
  затем два вопроса: какой плод и где был жук. С уровнем показ короче (от 0,9 до 0,22 секунды), мест больше,
  появляются отвлекающие листья.
- **Карта сильных сторон** на странице «Прогресс»: четыре направления, по десяти последним раундам каждого с учётом
  уровня.

## На что это опирается

Перед версией 3.7 я посмотрел, как устроены известные сервисы тренировки мозга и что известно о пользе.

- У Lumosity есть «тренировка дня» и серии дней подряд, у Peak — тренер с личной программой, у CogniFit — оценки по
  отдельным направлениям. Отсюда тренировка с помощницей и карта сильных сторон; серия дней в НейроСаде уже была.
  Источник: [сравнение приложений, 2026](https://unstar.app/blog/lumosity-elevate-peak-cognifit-neuronation-brain-training-apps-ranked-2026).
- Исследование ACTIVE (2832 пожилых участника): через 20 лет у тех, кто проходил тренировку скорости обработки
  информации с повторными занятиями, диагнозов деменции было примерно на 25% меньше; у тренировок памяти и
  рассуждения такого результата не нашли. Задание в том исследовании: быстро решить про объект в центре и
  одновременно заметить объект на краю, с нарастающей трудностью. Источник:
  [Being Patient, 2026](https://beingpatient.com/can-brain-training-reduce-dementia-risk-20-years-later/).
- Этот результат оспаривают: из двадцати с лишним проверок пользу показали две, группа с повторными занятиями могла
  отличаться от контрольной, один из авторов связан с продавцом программы.

«Двойное решение» в НейроСаде — упрощённая игра того же типа, а не то самое упражнение. Она не проходила никаких
исследований, и сайт ничего не обещает: в подвале по-прежнему написано «не диагностика и не лечение».

Губы двигаются по тексту, который произносится: буква за буквой, с подстройкой по сигналам браузера о начале слова,
когда браузер их присылает. Звук при этом не анализируется: у браузерного синтеза нет звукового потока, к которому
можно подключиться. Поэтому совпадение с голосом приблизительное.

Если в браузере нет 3D или модель не загрузилась, показывается простое нарисованное лицо, кнопки и голос работают
так же. Если в браузере нет голоса, правила и подсказка остаются текстом.

## Песочница

- `const SB_URL='', SB_KEY='';` в `index.html`: база не подключена, страницы не обращаются к Supabase. Режим
  «Аккаунт» и «Панель Ромы» в песочнице недоступны, всё хранится в браузере.
- Ссылки языков в шапке относительные, чтобы не уводить на основной сайт.
- При переносе в `main` эти два места возвращаются к значениям из `main`; остальное переносится как есть.
- GitHub Pages публикует только `main`, поэтому песочница на адресе сайта не видна. Локальный просмотр:

```
git checkout sandbox-3d-helper
python3 -m http.server 8080
# открыть http://127.0.0.1:8080/
```

## Файлы

- `helper.glb` — модель, 1,4 МБ.
- `helper3d.src.js` — исходник модуля; `helper3d.js` — он же, собранный в один файл вместе с three.js.
- `build-model.mjs` — как `helper.glb` получен из исходной модели.
- `../tests/helper-test.py` — проверки помощницы, тренировки, совета по уровню и карты; игра «Двойное решение»
  проверяется в `../tests/games-test.py`.

Модуль и модель загружаются только при открытии игры, главная страница от них не тяжелеет.

`mount(canvas, source)` принимает адрес модели или её байты (`ArrayBuffer`). Второе нужно там, где хостинг не отдаёт
файлы `.glb`: приватный просмотр в Claude получает модель как текст внутри скрипта.

## Происхождение и права

- **Модель.** Пример `avatars/mpfb.glb` из проекта [TalkingHead](https://github.com/met4citizen/TalkingHead)
  (SHA256 исходного файла `63c645a2a863b9972e9a9c2ed576a1de4c390b8475508e1473e69c87a3ee299c`). В README проекта
  указано: создана в Blender с расширением MPFB, лицензия [CC0](https://creativecommons.org/public-domain/cc0/).
  Для НейроСада модель уменьшена: оставлены 19 форм лица из 66, текстуры сжаты, геометрия упакована (36,8 МБ → 1,4 МБ).
- Модели AvatarSDK и Avaturn из Инфоцентра сюда **не взяты**: их условия разрешают только локальное некоммерческое
  использование, выкладывать их в открытый репозиторий нельзя.
- **three.js** r186 — MIT. **meshoptimizer** (распаковка геометрии) — MIT.

## Сборка

```
npm install three@0.186.1 esbuild @gltf-transform/core@4 @gltf-transform/extensions@4 @gltf-transform/functions@4 meshoptimizer sharp
npx esbuild helper/helper3d.src.js --bundle --format=esm --minify --target=es2019 --legal-comments=none --outfile=helper/helper3d.js
node helper/build-model.mjs mpfb.glb helper/helper.glb      # только если нужно пересобрать модель
```
